# 宿舍管理系统 · 页面展示

[返回项目首页](../README.md) · [快速体验](../README.md#快速体验独立-sqlite-演示库) · [报修流程说明](REPAIR-WORKFLOW.md)

基于 Vue 3、Vite、Spring Boot 4 和 Spring Security 的宿舍管理系统，支持管理员、楼栋宿管、辅导员、学生和维修人员协作。

以下 11 张截图于 **2026-11-05** 从当前项目运行页面截取，主要展示管理员视角。截图使用独立 SQLite 演示库，包含 **3 栋楼、12 间宿舍、24 名学生、48 个床位和 6 张报修工单**；姓名、学号、楼栋及报修内容均为虚构数据。

支持按楼栋、楼层、房型、入住状态和性别筛选，查看各房间容量及入住人数，并进入房间的入住详情。

![宿舍管理：宿舍房型、容量、入住人数与条件筛选](images/06-dormitories.png)

## 宿舍入住详情

在房间详情中查看当前住户、学号和班级信息，并提供按已建档学号安排入住的入口。演示学生不填写真实手机号。

![宿舍入住详情：当前房间两名演示学生及入住安排入口](images/07-residents.png)

## 报修工单

将“派单状态”和“维修进度”分别展示，区分“待派单 / 已派单”与“待处理 / 处理中 / 待验收 / 已完成”。未完成工单优先展示，同阶段中紧急工单优先。

列表展示故障描述、负责人、普通或紧急优先级、自动或人工判断来源及依据，支持筛选待派单工单。表格可横向滚动查看右侧验收意见和操作。

![报修工单：六张演示工单的派单状态、维修进度与优先级判断依据](images/08-work-orders.png)

## 派单窗口

管理员或负责楼栋的宿管选择维修人员并填写处理说明。优先级默认自动判断，也可人工调整为普通或紧急；自动规则只确定处理顺序，维修人员由工作人员指定。

![派单窗口：选择演示维修员、设置优先级并填写处理说明](images/09-dispatch.png)

## 工单处理记录

记录每一步的操作人、操作类型、说明和时间。截图用一张已完成的演示工单展示从提交到验收的记录。

```text
学生提交 → 管理员 / 宿管派单 → 维修人员开始处理 → 提交验收 → 学生验收通过
```

验收通过后结单；未通过则退回“处理中”，保留原负责人。维修人员完成维修仅进入“待验收”，不直接结单。

![工单处理记录：提交报修、派单、开始维修、提交验收与验收通过](images/10-work-order-history.png)

本流程对应后端 [WorkOrderService.java](../src/main/java/com/example/dormitory/business/WorkOrderService.java)，包括提交、派单、状态流转、验收和处理记录查询。完整规则见 [报修处理流程](REPAIR-WORKFLOW.md)。

## 床位管理

按房间与床号展示床位，分别标明房间状态和床位状态，支持查看当前入住学生。管理员及宿管可按权限安排入住、预留或调整床位状态。

![床位管理：宿舍床号、正常房间、已入住与空闲床位](images/11-beds.png)

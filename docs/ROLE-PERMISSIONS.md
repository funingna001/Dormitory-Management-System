# 页面与数据权限

菜单、页面渲染和后端接口分别校验角色。隐藏菜单不替代后端权限；手工请求接口仍须通过角色及数据范围检查。
切换账号后重新选择可用首页，并卸载上一个账号的页面组件。

| 功能 | 管理员 | 学生 |
| --- | --- | --- |
| 全校统计、AI 查询、学生和楼栋管理 | 可访问 | 无入口，接口拒绝 |
| 账号管理、批量导入、业务规则、操作记录 | 可访问 | 无入口，接口拒绝 |
| 床位 | 分配、预留及状态管理 | 本宿舍及可申请的同性别空床位查询 |
| 住宿申请、住宿历史 | 管理和审批 | 本人申请及历史 |
| 宿舍长 | 任命和交接 | 查看本宿舍宿舍长 |
| 费用 | 账单、收费与退款登记 | 本人账单及流水查询 |
| 访客 | 登记和管理 | 以本人为被访人的记录 |
| 物品 | 资产和交接管理 | 本宿舍物品及本人领用记录 |
| 检查 | 检查和复查 | 本宿舍结果与整改 |
| 报修 | 派单、处理和验收管理 | 提交报修及查看本人/本宿舍工单 |

宿管按负责楼栋、辅导员按所负责学生、维修人员按已派工单限制数据范围。
学生页面使用“我的费用账单”“我的住宿申请”等名称，共享业务页面不表示拥有管理权限。

回归验证：前端执行 `npm test`；后端执行 `mvn -Dtest=RoleBoundaryIntegrationTest test`。

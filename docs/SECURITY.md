# 安全说明

这里记录当前的认证、权限和数据保护方式。漏洞反馈方式见仓库根目录的 [SECURITY.md](../SECURITY.md)。

## 认证与权限

认证使用 Spring Security 和会话 Cookie。登录时更换 Session ID，写请求校验 CSRF token，退出使用 POST。密码以 BCrypt(12) 保存，空库管理员密码由 `ADMIN_INITIAL_PASSWORD` 设置。

学生账号由管理员核验后开通，公开注册接口返回 403。建档或导入遇到未绑定档案的同名账号时返回冲突，需要先核验，不能直接继承该账号的密码。

每次请求检查账号是否存在、是否启用、角色和凭据版本是否一致。改密、重置密码或停用账号后，旧会话会失效。数据库故障返回 503，保留已有会话，避免把服务故障当成密码错误。

接口按角色和业务范围检查权限：管理员查看全校数据，宿管限负责楼栋，辅导员限负责学生，维修人员限已派工单。学生的个人资料接口从当前会话获取身份，不接受客户端修改学号、角色、宿舍或宿舍长属性。各页面权限见 [权限说明](ROLE-PERMISSIONS.md)，认证细节及限流配置见 [认证与会话](AUTH-HARDENING.md)。

## 数据修改

入住人数由后端计算。入住、调宿和退宿在事务中检查性别、容量、房间状态、床位归属及费用和物品交接；并发操作按固定顺序加锁。楼栋更名保留房间编号关联，缩容或删除前检查现有住户。

学生归档保留住宿历史和费用流水。批量导入、分配先预览再确认，批次有归属、有效期和单次确认限制；确认时重新检查状态，发生冲突时整批回滚。实现说明见 [业务说明](BUSINESS-FEATURES.md) 和 [事务与锁](OPTIMIZATIONS.md#事务与锁)。

SQL 值使用占位参数，排序字段使用白名单。错误响应不包含 SQL、服务器路径或调用栈；详细异常写入服务端日志，用户对象不序列化密码。

## 附件和导入导出

上传图片只接受有效 PNG/JPEG，限制文件大小为 5MB，并检查像素数和并发量。图片重新编码为随机文件名的 PNG，通过业务记录鉴权读取，附件目录没有公开静态映射。

XLSX 导入限制文件大小、行数和压缩包展开量，拒绝公式单元格。导出只允许管理员使用，不包含密码、凭据版本、导入预览正文或附件文件。Excel 导出用于查阅，完整恢复应使用 [数据库与附件备份](BACKUP-RESTORE.md)。

## 统计助手

DeepSeek Key 从后端环境变量读取，前端只获得配置状态。模型接收本次提问和允许的查询类型说明，后端按固定 SQL 读取统计，不执行模型生成的 SQL，也不发送数据库统计结果。

未配置密钥或调用失败时返回本地统计。查询仅管理员可用，每账号每分钟最多 10 次。统计口径和功能限制见 [统计助手](AI-ASSISTANT.md)。

## 部署配置

后端默认只监听本机。公开部署时通过受控反向代理提供 HTTPS，并设置 `COOKIE_SECURE=true`。Cookie 使用 HttpOnly 和 SameSite=Lax；CORS 只允许配置中的来源。

[Nginx 示例](../deploy/nginx.conf)设置了 CSP、nosniff 和 frame-ancestors 等响应头，并覆盖客户端传入的转发头。后端默认只信任回环代理；代理不在本机时，需用 `TRUSTED_PROXY_PATTERN` 指定受控地址。

`.env`、数据库、附件、备份和日志不应提交到仓库。旧版配置曾包含 API 密钥，使用过旧配置时应在供应商处撤销并重新生成；删除配置文件不会使旧密钥失效。旧密码迁移到 BCrypt 只改变存储方式，仍需更换弱密码。

## 兼容与检查

启动时迁移旧的明文密码，并兼容 SQLite 历史报修时间字段。新记录统一使用 Timestamp 写入，读取时兼容旧的带 `T` 日期字符串，只有确实查无记录时才返回 404。

后端测试覆盖认证、CSRF、角色与数据范围、会话撤销、并发入住、报修流转和导入导出。测试使用临时数据库，运行方式见 [参与开发](../CONTRIBUTING.md)。

前端依赖可用 `npm audit` 检查，后端可用 `scripts/audit-dependencies.py` 查询 OSV。审计结果随依赖版本和漏洞库变化，需要在发布时重新检查；历史扫描结果不能作为当前版本的安全结论。
